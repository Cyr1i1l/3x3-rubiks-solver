# 3x3-rubiks-solver
Repository for software pairing with a physical 3x3 Rubik's Cube solver, aimed to accommodate any 3x3 Rubik's cube, and to teach solving / hone solving skills to beginners or experienced solvers.

This repository will contain all software relating to the solver. Intended contents are:
- Picture taking, scanning, and interpreting scan results as 2D representation
- 2D cube manipulation, moving, algorithm intake and parsing, solve history
- UI/UX visuals, layout, and how it interacts with other components
- Wrapping 2D representation of cube onto 3D model for display on UI screen
