Python uses virtual environments to create a dedicated place local to the folder where dependencies can be installed. I created the virtual environment, but it should be activated before you install dependecies and before running code that uses those dependencies.

To activate the python virtual environment:
    Linux and Mac CLI "source venv/bin/activate"
    Windows PowerShell "venv\Scripts\Activate.ps1"
    Windows Command Prompt "venv\Scripts\activate.bat"
