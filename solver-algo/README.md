# Folder for solver algorithm/data manipulation related files

Solver algorithm currently parses a string of moves and performs them on a 3D model displayed in its own window.
To test:
1. download cube3dDisplay, moveCube, and cubeImager .py files
2. download cubeImages/currentCube.png, blenderfiles/test cube.mtl and blenderfiles/test cube.obj
      IMPORTANT: keep files in their respective folders!!!
3. in VS Code, "pip install ___" necessary libraries and run cube3dDisplay.py
